# Image Classification Using Pretrained Model 🖼️

## CodeOrbit Tech Internship – Task 3

### 👩‍💻 Project Overview

This project demonstrates image classification using a pretrained deep learning model called MobileNetV2.

The project uses TensorFlow to load a pretrained model and classify sample images. It predicts the objects present in images and displays the top 3 predicted labels with their confidence scores.

### 🎯 Project Objectives

- Understand pretrained deep learning models.
- Use MobileNetV2 for image classification.
- Load and process sample images.
- Predict image categories using AI.
- Display predicted labels and confidence scores.

### ✨ Features

- Uses a pretrained MobileNetV2 model.
- Classifies sample images.
- Displays top 3 predictions.
- Shows confidence percentages.
- Uses TensorFlow for image processing and prediction.
- No need to train a model from scratch.

### 🛠️ Technologies Used

- Python
- TensorFlow
- MobileNetV2
- NumPy
- Matplotlib
- Jupyter Notebook

### 🧠 Pretrained Model Used

**MobileNetV2**

MobileNetV2 is a pretrained image classification model trained on the ImageNet dataset.

It can recognize different objects and predict their categories based on image features.

### ⚙️ Project Workflow

1. Install TensorFlow.
2. Import required libraries.
3. Load the pretrained MobileNetV2 model.
4. Download sample images.
5. Resize and preprocess images.
6. Make predictions using the model.
7. Display the top 3 predicted labels and confidence scores.

### 📊 Sample Classification Results

The project tested two sample images:

- Dog Image – Predicted Labrador Retriever.
- Person Image – Classified using MobileNetV2.

The model displays the top 3 predictions with their confidence scores for each image.

### ▶️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open Jupyter Notebook.

```bash
pip install tensorflow
```

6. Run all notebook cells in order.
